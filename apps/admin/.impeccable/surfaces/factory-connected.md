# Factory — one operational journey

Mode: Operate. Extend the incumbent Audit1 Lime/Geist system, not the landing identity. No new palette, global tokens, raster assets or application shell.

THESIS: a single understandable journey — source, workspace workflow or individual agent, execution, evidence, human decision. Make the difference between both execution engines explicit without duplicating the top-level navigation.

OWN-WORLD: retain shared controls, neutral surfaces, modest depth, restrained lime actions and meaningful semantic status. Domain controls can remain native. Technical details belong behind intentional disclosures, not in raw JSON walls.

STORY: the operator sees an honest next action, reuses a versioned agent profile, selects an execution harness, then sees exactly which definition/model ran. Authentication is local to the machine; selecting a name never claims a missing adapter is installed.

FIRST VIEWPORT: Factory title, real state or explicit missing-data state, one primary action and scoped workspace information. Agent forms lead with profile/harness/model; once-only runner infrastructure is disclosed. Pending work and evidence link to the shared execution entry point.

FORM: eight daily navigation entries; advanced permissions and infrastructure in Configuration; evaluation/decision tools in Laboratory. Preserve historical routes and data. No merges, live paid models or production configuration changes during design verification.

REVIEW CONTRACT: one batched desktop/mobile round, one defect-fix batch if necessary, at most one confirmation round. Fixtures are labelled and the preview rejects every mutating API request. Owner visual approval is required before publication/deployment.

Verification: desktop 1440×1000 and mobile 390×844 across ten routes (20 states). Initial batch followed by a single confirmation batch: shorter role intro, human blocker summaries and semantic run statuses. Confirmation metrics: zero JS errors, external requests, page-width overflow or overflowing form fields. Artifacts: `/tmp/nexusmind-build-tools/factory-connected-confirm/`. Browser smoke opens pending → run detail and preserves model/policy legacy routes. Preview GET 200; PATCH 405. No paid model or production acceptance claimed.

Documentation: `docs/factory/FACTORY_CONNECTED.md`. Important boundaries: existing engines and storage remain distinct; native source deduplication remains workspace-scoped; unconfigured harnesses and QA assets remain blocked. Shared pause requires both autonomous-agent and factory-workflow write authority. Historical role-model preferences do not silently reactivate old agents.

# NexusMind landing

NexusMind is an open-source AI control plane: persistent cross-tool memory, SDD artifacts, team tasks, shared harnesses, agents, policy, audit and administration in the user's infrastructure. Product copy is sourced from the existing repository landing and README; the eleven capability descriptions live in `src/lib/features.ts`. The canonical repository, documentation, issue, pull-request and MIT-license URLs live in `src/lib/repository.ts`. The examples in the hero are explicitly illustrative, not production activity or customer evidence.

The owner selected the SmartCoder/Globant lime design as the sole landing on 9 October 2026 and discarded the earlier blue landing. `/` is canonical; `/smartcoder` redirects to `/` for existing preview links. No waitlist, pricing, invented customer metrics or signup form belongs to this page.

Visual commitments: Heebo, black navigation, white/lime light mode, dark green dark mode, editorial split sections, original owner-supplied conceptual images. Both themes are persistent. The owner explicitly requested the interactive 3D mesh, cursor deformation, click waves and native-scroll chapter animation. Reduced motion retains readable static content; the animated background has a pause control and suspends offscreen or when the document is hidden.

The same lime identity is authorized for the admin as a subsequent work item. Landing publication is authorized; the admin must remain local for owner review before any admin changes are pushed. Do not publish admin changes with the landing.

Sources: repository README and current capability copy; owner reference `https://www.smartcoderlabs.com/#ideas`; local SmartCoder design pack `design/globant-inspired/DESIGN.md`. Image provenance and the Heebo license accompany assets in `public/smartcoder/`.

# Signal principles (admin + backoffice)

Signal is the design language; the SmartCoder palette is its colour. Both arrive with PR #464. The system came from the Signal kit (tokens, glass, motion, phi), not from its landing sections, and carries no brand, copy or assets from the kit's source.

## Palette roles

| Role | Light | Dark | Use |
|---|---|---|---|
| Structure | ink `#111114`, charcoal `#101114` | foreground `#f2f4f7` on charcoal | text, frame, neutrals |
| Primary action | forest `#356b26`, white text (6.4:1) | `#7fbe6f`, ink text (8.5:1) | filled primary actions |
| Signal accent | lime `#c3d82e` | same | focus ring (dark), `sig-live`, highlight marks, hover edge, gradient ends. About 5% of a screen |
| Soft fills | pale `#e7f4d8`, mint `#84e6b0` | tint `#293e28` | selected nav, tinted chips |
| Data d1..d4 | green `#356b26`, blue `#285f91`, teal `#286f68`, amber `#805b0d` | `#91d281`, `#9bc8ed`, `#82cbbf`, `#e6c16d` | data series, fixed order |

Dark values are OKLCH derivations: same hue, lightness raised into the 0.74–0.82 band. The accent block is generated by the kit's `rebrand.mjs '#c3d82e'`.

## The rules that matter

1. **Lime is the accent only, never a fill for large surfaces or body text.** It reads 1.6:1 on white; on light surfaces use `--sig-text-light` `#677302` (5.2:1) when lime must be seen. `design-audit.mjs` D-COL-01 enforces it.
2. **One accent.** No second brand colour. Data hues are data, not decoration; status colours are status.
3. **Two glass levels.** glass-1 for cards on the frame, glass-2 for the frame and floating layers. The frame shows one green haze, one cool haze and a faint 55px grid behind it.
4. **Numbers are the heroes of a stat card.** Use `text-kpi` and tabular numerals. The label is muted 13px, and one data-hue icon chip comes from the card's `accent`.
5. **One curve.** Use `--ease-signal` (expo-out) for every entrance. Motion respects `prefers-reduced-motion`. See `motion.md`.
6. **Proportion.** Use phi spacing (5/8/13/21/34/55/89) and the golden type scale (11/14/18/23/29/37). Geist only.
7. **Re-skin through tokens.** Change the token sheets and the shared components, not page markup, routes or data.

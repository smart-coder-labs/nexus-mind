# Architecture Decision Records (ADR)

Este directorio contiene los Architecture Decision Records de NexusMind.

Los ADR documentan decisiones arquitectónicas significativas, incluyendo el contexto, las opciones consideradas, la decisión tomada y las consecuencias.

## Estado de un ADR

- **Propuesto**: En discusión, no implementado
- **Aceptado**: Decisión tomada, pendiente de implementación
- **Implementado**: Decisión ejecutada
- **Superseded**: Reemplazado por un ADR posterior
- **Rechazado**: Descartado
